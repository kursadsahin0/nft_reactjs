# NFT Marketplace UI

A responsive landing page for an NFT marketplace built with React. It includes a hero banner, featured items, collections, creators, a newsletter section and a contact form.

## Features

- Component-based layout (Navbar, Banner, Items, Collection, Creator, Newsletter, Contact, Footer)
- Carousel sliders for items and collections (react-slick)
- Data-driven cards rendered from a local data file
- Responsive design

## Tech Stack

- React
- react-slick, slick-carousel
- React Icons, react-ionicons
- CSS

## Getting Started

```bash
npm install
npm start
```
